# Fixtures

| File | Where it came from |
|---|---|
| `music-video.fcpxml` | Copied unchanged from fcp-mcp-server 0.30.0 `examples/` (MIT, Copyright (c) 2025 DareDev256; license in `LICENSE-fcp-mcp-server`). A music video whose spine is one gap with every clip connected, at 23.976 with a 50p source, offsets on a 3600s clock. |
| `sample.fcpxml` | Copied unchanged from the same `examples/` folder, same license. A spine-based interview cut at 24 fps. It is not valid against Apple's DTD (assets use the pre-`media-rep` `src` attribute, chapter markers sit on the `<sequence>`); `scripts/scenarios.py::normalize_sample` makes a valid 1.13 copy of the same cut for the tests. |
| `LICENSE-fcp-mcp-server` | fcp-mcp-server's MIT license, kept with the files it covers. |
| `music-video.notes.txt` | Written for these tests: six placeable notes, one with no timecode, one past the end of the cut, one with an impossible timecode, one timecode with no note. |
| `sample.frameio.csv` | **A reconstruction, not a real Frame.io export.** The column names come from V3-era sources (see DECISIONS.md, the Frame.io entry). It exercises replies, a completed comment, a drawn-on comment, a comment with no timecode and an unreadable timecode. Replace it with a real export when one exists. |

The second version of each cut, and the fcp-mcp-server journal that records how it was made, are generated by `scripts/scenarios.py` on every test run, never committed: the journal records absolute paths.
