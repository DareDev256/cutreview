# Support

Cut Review was built for one editor's review round in Final Cut Pro and is shared as it is, free, under the MIT license.

- **Bugs:** open an issue with the command you ran, what it printed, and if you can, the FCPXML export and notes file (only files you are free to share). A bug report with the file in hand gets fixed fastest.
- **Frame.io V4 exports:** the importer reads columns by name and has not yet met a real V4 export. If yours does not read, the header row alone is enough to fix it.
- **Questions:** GitHub Discussions or an issue.

Issues are read and answered as time allows. There is no guaranteed response time.
