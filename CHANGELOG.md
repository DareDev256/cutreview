# Changelog

## 0.1.0 (2026-11-12)

First version. Not yet published.

Added:

- `cutreview diff OLD NEW`: one self-contained HTML page of what changed between two Final Cut exports. Clips are matched by source material, so ripples, head trims and gap-based (all connected) cuts read correctly. Timeline strip with changed ranges marked, before and after source frames when the media is on the machine, both file hashes and export times.
- `cutreview blame OLD NEW`: each change attributed to the fcp-mcp-server tool call that wrote it, from that server's sha256 journal; work after the last journaled write reads "not in the journal".
- `cutreview notes CUT NOTES`: plain text with timecodes, generic CSV and Frame.io comment CSV written into the cut as to-do markers on the clip under each note, in its source time. Unplaced notes and unreadable lines are listed with reasons and kept in a JSON ledger. Every write is checked against Apple's FCPXML DTD and read back through fcp-mcp-server's parser before it is kept.
- `cutreview status MARKED NEXT`: each note done or open (the editor's tick) and touched or untouched, leading with ticked but untouched and changed but not ticked; "removed with its clip" and "its frames were cut" when the material is gone.
- `cutreview mcp`: one MCP tool, `review`, with actions diff, blame, notes, status, over stdio, on mcp 1.x or 2.x. Writes stay inside the cut's folder.
- 91 tests, 17 guard mutations (`scripts/mutate.py`), a demo round on synthesized media (`scripts/make_demo.py`) and a rendered page check at 1440 and 390 in both colour schemes (`scripts/screenshots.py`).
- Launch preparation, nothing published: `docs/launch.md` (audiences and their search phrases, the demo and its footage, where it is shown, the launch-day checklist, drafts, the first week of issues, what holds the launch); the README's first line and the package description rewritten around those phrases; `server.json` for the MCP registry with the `mcp-name` line in the README; `scripts/social_card.py` (1280x640, true black, one cyan, the real status page as the picture, refuses on any overlap); `scripts/save_traffic.py`, which keeps GitHub's 14-day views, clones, referrers and paths, with its tests. README links now point at github.com/DareDev256/fcp-mcp-server, the repo's current name.
- Search and answer-engine pack, nothing published: the README opens with a one-sentence definition, a 60-second `uvx` quick start, a FAQ whose headings are the questions editors search, and a comparison with Change List X, Marker Toolbox and Frame.io V4 read from their own pages; every README image is an absolute URL pinned to the v0.1.0 tag so PyPI shows it. A GitHub Pages site in `docs/` (one static page, no tracking, JSON-LD for the software and the FAQ, Open Graph card, sitemap, robots.txt, llms.txt), built by `scripts/build_site.py`, whose `--check` refuses a stale page and 15 kinds of drift (each mutation-checked). PyPI metadata: summary led by the search phrase, keywords, classifiers for Python 3.10 to 3.14 (the suite passes on each), project URLs. `server.json` gains the site and an icon. The social card is re-rendered from the demo status page with the phrase as its subtitle.
